# Edges (one-shots)

- A **rising edge** passes power for exactly one scan when its tag goes from FALSE to TRUE.
- A **falling edge** passes power for exactly one scan when its tag goes from TRUE to FALSE.
- Use an edge to do something **once** per event: count a part, reset a memory when a part has passed, toggle a mode.
- Allen-Bradley: ONS (one-shot) after the contact, or OSR/OSF.
