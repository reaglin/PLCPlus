# Module check: relay control

This check covers the four items of module 3. Each of them is complete once you have read it and pressed **I have read this** on its Learn tab.

When all four are complete, this module is complete. In a later version of PLC+ the check will also have questions (spec 7.3), and finishing it will make a progress report to hand in to your instructor.
