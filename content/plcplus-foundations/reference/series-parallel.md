# AND and OR with contacts

**Series = AND.** Power passes only if every contact passes.

[[truth-table: A AND B]]

**Parallel = OR.** Power passes if any path passes.

[[truth-table: A OR B]]

**Normally closed = NOT.** A normally closed contact of A passes power when A is FALSE.

## Current, voltage and resistance

| | Series | Parallel |
|---|---|---|
| Current | Same through every part | Adds up across branches |
| Voltage | Shared between parts | Same across every branch |
| Total resistance | R1 + R2 + … | Less than the smallest; two branches: (R1 × R2) / (R1 + R2) |
| One part opens | Everything stops | Only that branch stops |
